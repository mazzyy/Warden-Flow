Models swappable per node — Google Gemini 3.5 · Azure OpenAI GPT‑5.6 · OpenAI · Anthropic.

Run the DELIVER workflow
Offline (default): analyses the bundled sample app — free, instant, no credentials. Tick run live to clone and analyse your own repo (a GitHub URL works) with the model in your .env.
Connect your project

1Point the agent at your repo

The workflow reads a local directory. Use the box above, or the CLI with any folder:

make deliver-live \
  # or:
./.venv/bin/python -m warden.deliver \
      --target /path/to/your/repo --live

Assess reads your dependency manifest and entrypoint; the rest of the workflow builds on that.

2Choose the model (optional)

Default is Gemini. To run on your Azure GPT‑5.6, add to .env:

DELIVER_MODEL=azure/gpt-5.6-sol
AZURE_API_KEY=…
AZURE_API_BASE=https://<resource>.openai.azure.com/
AZURE_API_VERSION=2024-12-01-preview

Every node then runs on that model — same governance and typed output.

3Review & ship

The workflow opens the generated Dockerfile, pipeline and manifests as a pull request. A human approves — that's the only step that changes production.

4Prove it beats a single prompt

The benchmark scores the same job both ways, on the real Dockerfile:

make bench-deliver
