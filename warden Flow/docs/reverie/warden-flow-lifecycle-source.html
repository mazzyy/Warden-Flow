Warden Flow

an AI DevOps engineer — one structured-prompting engine, two workflows
Every node runs one narrowly-scoped LLM query, returns a typed object, and hands that structure to the next node. The only step that changes production is a human merge. Model per node is configuration, not code.
Models (swappable per node): Google Gemini 3.5 · Azure OpenAI GPT‑5.6 · OpenAI · Anthropic — via one resolver.
