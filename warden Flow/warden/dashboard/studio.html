Connect your project

1Point it at your repo

Paste a GitHub URL above and tick run live, or from your project folder:

warden-deliver --live

2Open a PR (token)

Tick open PR + set GITHUB_TOKEN (Contents · Workflows · Pull requests: write) to push the DevOps back as a pull request.

GITHUB_TOKEN=github_pat_…

3Model (optional)

Default Gemini; for Azure GPT‑5.6 add to .env:

DELIVER_MODEL=azure/gpt-5.6-sol

4Deploy

Merge the PR → the generated pipeline builds, pushes to ACR and deploys, using your repo secrets.

make bench-deliver   # single prompt 0/5 vs workflow 5/5
